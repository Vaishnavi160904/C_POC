# Job Requirement Menu

The HR-facing job requirement submenu is intentionally simplified to the two operations needed in the normal screening workflow:

```text
--- Job Requirement ---

1. Upload/Load Requirement File (.txt or .pdf)
2. View Current Requirement
3. Back
```

- **Upload/Load** accepts a TXT or PDF job requirement and extracts the required technical skills.
- **View Current Requirement** displays the skills currently loaded in memory; it does not ask HR to re-enter a file path.
- **Back** returns to the HR main menu.

File editing/deletion/reloading are intentionally not exposed in the HR menu.
